# 运航部值班干部航前风险提示记录表

## 输入与默认路径

- 出港签到表：用户附件（.xlsx）。广州 sheet 标题如「2026年10月09日广州出港签到表」。
- 风险文件夹：默认 `C:\Users\Administrator\Desktop\飞行资料\风险`（存放历史记录表 docx 与产物）。

## 执行步骤

1. **读取输入**：用 `sheet` 技能或 openpyxl 解析签到表，确认标题日期、表头（航班/航程/当日机组）、航班行与「备份机组」行。默认仅取标题含"广州"的工作表（贵阳等其它 sheet 不纳入，除非用户明确要求）。
2. **运行生成脚本**（推荐路径）：

   ```powershell
   python "<技能目录>/scripts/build_record.py" --signin <签到表xlsx路径> --risk-dir <风险文件夹>
   ```

   参数：
   - `--signin`（必填）签到表路径
   - `--risk-dir` 风险文件夹（默认桌面飞行资料\风险）
   - `--out` 输出路径（默认 risk-dir/运航部值班干部航前风险提示记录表{M.D}.docx，M.D 如 10.9）
   - `--date` 可选，YYYY-MM-DD，默认从签到表标题解析
   - `--sheet` 可选，指定工作表名
   - `--backup` 可选，备份机组名单逗号分隔，默认从签到表"备份机组"行读取

   脚本会自动：解析航班号（AQ1055/1060/1059 → AQ1055/AQ1060/AQ1059）与航线缩写（穗(CAN)-锡(WUX)-… → 穗-锡-…）、按航线匹配历史风险、选最新模板重建表格、写入日期与备份机组、行高按内容自适应。
3. **核对脚本输出**：航班数、备份机组、未匹配警告（风险内容留空的航班需人工补充）。如有未匹配航班，检查航线缩写是否与历史表一致，或提示值班干部人工补写。
4. **校验产物**：读取 `word` 技能并按模板创建流程运行 audit（`scripts/audit.py audit <产物> --source <所用模板>`），0 错误后再交付。
5. **交付**：通过 `present_files` 交付 docx 文件（保留原文件名）。

## 匹配规则（脚本已实现，必要时人工复核）

- 航线匹配：先精确匹配历史航线（如 穗-锡-穗-锡）；无精确匹配则匹配同起降点（首末机场相同，如 穗-锡-营-锡 可服务 穗-锡-穗-锡）；取该航线**最新一次出现**（按文件修改时间）的记录。
- 风险类型：沿用历史记录中的 ☑ 勾选（机组/飞机/航线/天气/机场/标准/程序/其他）。
- 模板：取风险文件夹中表头含 航班号/航线/风险类型/风险提示内容、修改时间最新的 docx；仅当用户要求或模板缺失时才考虑改用更早模板。
- 行高：按内容行数自适应（hRule=exact），保证文字不被裁切。

## 注意事项

- 产物命名沿用历史惯例：`运航部值班干部航前风险提示记录表{M.D}.docx`（月份日期不补零）。
- 签字段日期写为 `日期：YYYY年MM月DD日`（月日补零，如 2026年10月09日）。
- 不修改历史记录表原件；每次只基于最新模板生成新文件。
- 若签到表结构变化（表头列名不同、备份行格式不同），先人工确认解析结果再生成。
